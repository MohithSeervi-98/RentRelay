# Booking workflow\n\n1. Borrower selects an available listing and dates.\n2. Backend checks availability and creates a request.\n3. Lender accepts or rejects.\n4. Borrower reviews fees, deposit terms and return rules.\n5. Payment is processed by an approved provider.\n6. Both parties document condition at handover.\n7. Return condition is documented.\n8. Deposit settlement follows disclosed rules; disputes go to admin review.\n\nBackend must enforce status transitions; do not trust browser-submitted status changes.\n
