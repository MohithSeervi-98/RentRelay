# RentRelay

Campus-first peer-to-peer rental marketplace for students.

## Project structure

- `frontend/` — static web prototype (HTML, CSS, JavaScript)
- `backend/` — API server and application logic
- `database/` — SQL schema and seed data
- `docs/` — product requirements and workflows

## Current status

Starter project structure. Authentication, shared database, booking lifecycle, payments, and dispute handling are not production-ready yet.

## Local setup

Open `frontend/index.html` with VS Code Live Server to preview the static prototype.
